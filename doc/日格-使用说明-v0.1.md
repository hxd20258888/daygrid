# 日格 · 使用说明（Windows 桌面版 v0.1）

## 怎么启动

- 双击 `F:\自用小工具\windows\日格.lnk`
- 或直接运行 `F:\自用小工具\windows\dist\日格\日格.exe`

启动后桌面右侧会出现日历组件，托盘里常驻一个日格图标（蓝色小格子）。关掉窗口只是收进托盘，不会退出。

## 三个界面

| 界面 | 打开方式 | 用途 |
| --- | --- | --- |
| 桌面组件 | 启动即在 | 看本月、看今天，双击日期速记 |
| 速记浮层 | `Ctrl + Alt + Space` | 一句话记日程，自动识别日期/时间/标签 |
| 完整窗口 | 组件右上角「···」/ 托盘点「打开日格」 | 时间轴、日历、复盘、设置 |

## 快捷键

| 动作 | 快捷键 |
| --- | --- |
| 速记 | `Ctrl + Alt + Space` |
| 显示 / 隐藏桌面组件 | `Ctrl + Alt + D` |
| 搜索 | `Ctrl + K` |
| 新建条目 | `N`（不在输入框时） |
| 关闭弹层 | `Esc` |

速记里可以直接写：

```
明天下午3点 和张总过方案 #工作 !高
每周一 9:00 周会
每月5号 交房租 @生活
30号前 写完季度总结 ~2h
```

支持：今天/明天/后天/周X/下周X/MM月DD日、上午/下午/晚上 + 几点、`-` 时间段、`#标签`、`@清单`、`!高/中/低`、`~30m` 预计耗时。

## 数据存在哪

**全部数据都在本机，不联网、不上传。**

| 内容 | 路径 |
| --- | --- |
| 主数据库（SQLite 单文件） | `C:\Users\<你的用户名>\AppData\Roaming\DayGrid\data\daygrid.db` |
| 每日自动备份 | `...\DayGrid\data\backups\daygrid-YYYY-MM-DD.db`（保留 30 份） |
| 缓存 / 窗口状态 | `...\AppData\Roaming\DayGrid\`（Cache、GPUCache 等，可删） |

说明：

- 条目、清单、每日一句、设置全在 `daygrid.db` 里，**备份就是复制这一个文件**。
- 「设置 → 数据位置」里可以直接打开目录、立即备份、导出 JSON。
- 想换电脑：把 `daygrid.db` 拷到新机的同一路径即可；或导出 JSON 再导入（导入功能还没做，v0.2 补）。
- 数据目录可以用环境变量 `DAYGRID_DATA_DIR` 改到别处（比如同步盘），但多台设备同时写会有冲突，暂不建议。

## 首次打开与清空示例

第一次启动会载入一组示例条目（周会、改预算表、取快递……），方便你直接看到界面效果。

不想要就在「设置 → 清空数据」里清空，会删除全部条目与每日记录（不可恢复，建议先导出）。

## 手机端（v0.2）

手机端是一个 Android App（`apps\android\日格.apk`），界面和数据都打在包里，**电脑关机也能打开、能记**。

同步走你自己的云服务器（服务器只存密文，看不到内容）：

- 电脑：设置 → 云同步 → 填服务器地址、空间 ID、设备 ID、设备令牌、同步口令 → 保存并同步；
- 手机：装 APK → 我的 → 数据与同步 → 填同样的服务器地址 + 电脑生成的配对码 + 同一个同步口令；
- 改完 2.5 秒自动推、回到前台自动拉，也可以手动点「同步」。

服务器怎么买、怎么部署，见 [日格-手机同步-设置指南](日格-手机同步-设置指南.md)。

## 提醒

- 到点前 10 分钟（可在新建时改），组件顶部会出现橙色提醒条，同时弹 Windows 通知。
- 只对「有时间」且「未完成」的条目生效。
- 关机/退出期间错过的提醒不会补发（v0.2 补「错过的提醒汇总」）。

## 外观主题

设置 → 主题，三选一：

- **浅色**：纸白卡片，主窗口和组件一致；
- **深色**：深灰底，夜里看不刺眼；
- **透明**：桌面组件半透明（约 62% 白），直接透出壁纸；主窗口和速记仍保持浅色，保证可读性。

切换即时生效，三个窗口同步，重启后保留。透明模式在花哨壁纸上字会有点花，看不清就切回浅色或深色。

## 新建条目的默认时间

点「＋ 新建」时，时间会自动填成**下一个整点或半点**，结束时间默认 +1 小时（例如 15:12 新建 → 15:30 – 16:30），不用手动填。

## 已知限制（v0.1）

- 拖拽改期、周视图 / 日视图还没做，改期请点开条目在编辑框里改。
- 「今日条」形态（只显示今天那条）还没做，等你确认要不要保留。
- 导入 JSON、手机同步还在后续版本。
- 只支持 Windows 10/11（需要 WebView2，系统一般自带）。

## 文件结构

```
F:\自用小工具\
├─ doc\                 方案、原型、说明文档
│  ├─ app原型\           手机端原型（HTML）
│  ├─ pc原型\            电脑端原型截图
│  └─ 日格-手机同步-设置指南.md
├─ windows\             桌面端源码与构建
│  ├─ src\              界面（widget / capture / app）
│  ├─ db.js             数据层（SQLite + 变更表）
│  ├─ sync-client.js    云同步客户端（加密、推送、拉取）
│  ├─ main.js           主进程（窗口、托盘、快捷键、提醒、同步）
│  ├─ test\             端到端测试（桌面 + 云同步）
│  └─ dist\日格\         可直接运行的成品
├─ server\              云端同步服务（部署到云服务器）
│  └─ server.js         盲存储：只存密文，配对、转发
└─ apps\
   ├─ mobile\           手机端页面（APK 内置的就是这一份）
   └─ android\          Android 安装包与打包脚本（日格.apk）
```
